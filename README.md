# جزوه‌های دانشگاه

سایت ایستای درس‌ها و جزوه‌های نیمسال اول ۱۴۰۵–۱۴۰۶، منتشرشده با GitHub Pages.

برای هر جلسه سه چیز در دسترس است: ویدیوی کامل، متن خام پیاده‌شده و جزوهٔ مصور در گوگل درایو.

## ساختار

```
index.html            فهرست درس‌ها
mis.html              سیستم‌های اطلاعاتی مدیریت
organization.html     نظریه‌های سازمان و مدیریت
marketing.html        مدیریت بازاریابی
selected-topics.html  مباحث منتخب
economics.html        اصول اقتصاد
style.css             طراحی مشترک، روشن و تاریک
theme.js              کلید حالت روشن/تاریک با ذخیره در مرورگر
course-visuals.jpg    تصویر هدر صفحه‌ها
data/courses.json     تنها منبع داده: درس‌ها، جلسه‌ها، منابع، پروژه‌ها
tools/build.py        سازندهٔ صفحه‌های HTML از روی داده
transcripts/          متن خام هر جلسه، یک فایل برای هر جلسه
```

## به‌روزرسانی

فقط `data/courses.json` را ویرایش کنید و بعد:

```
python tools/build.py
```

هر جلسه این شکل را دارد:

```json
{
  "n": 4,
  "date": "1405-08-24",
  "code": null,
  "seconds": 5970,
  "video": "http://mba-it.ir/vids/mis/03-1405-08-24-99min.mp4",
  "transcript": "transcripts/mis/03-1405-08-24.txt",
  "note": "1EDLw_O6iyRD9MHfk4EdbfEhb0PhNM6eo"
}
```

- `n` شمارهٔ جلسه است و همیشه با دو رقم نمایش داده می‌شود.
- `date` تاریخ جلسه به شکل `YYYY-MM-DD` است؛ اگر تاریخ معلوم نباشد `null` بگذارید و `code` را پر کنید.
- `seconds` مدت جلسه بر حسب ثانیه است.
- `note` شناسهٔ فایل جزوه در گوگل درایو است، نه لینک کامل.
- `flag` اختیاری است: `recording` برای جلسه‌ای که برگزار نشده و `text-only` برای جلسه‌ای که ضبط تصویری ندارد.

اگر نام استاد در `teacher` خالی باشد، صفحه جایش را با نشانهٔ «ثبت نشده» نگه می‌دارد.
